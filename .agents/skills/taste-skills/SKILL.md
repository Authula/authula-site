# Taste Skills

Each subfolder is a self-contained skill. Load the one that matches the work.

- `brandkit` — Generate premium brand-kit images: guideline boards, logo systems, identity decks and visual-world presentations.
- `design-taste-frontend` — Anti-slop frontend skill (v2, current default) for landing pages, portfolios and redesigns that infers the right design direction and ships non-templated interfaces with an audit-first, pre-flight-checked process.
- `design-taste-frontend-v1` — The original v1 frontend taste skill, kept only for projects that need its exact behaviour.
- `full-output-enforcement` — Force complete, unabridged code output with no placeholders and clean handling of token-limit splits.
- `gpt-taste` — Awwwards-level design engineering with randomised layout variance, AIDA page structure, wide editorial typography, gapless bento grids and strict GSAP ScrollTrigger motion.
- `high-end-visual-design` — Design like a high-end agency by prescribing the fonts, spacing, shadows, card structures and animations that make a site feel expensive while blocking generic AI defaults.
- `image-to-code` — Image-first website building: generate large section-specific design images, analyse them deeply, then implement the site to match.
- `imagegen-frontend-mobile` — Generate premium, app-native mobile screen concepts and flows inside subtle phone mockups (images only, no code).
- `imagegen-frontend-web` — Generate one separate horizontal design-reference image per website section, with varied composition and a single consistent palette, for developers to recreate.
- `industrial-brutalist-ui` — Raw mechanical interfaces fusing Swiss typographic print with military terminal aesthetics for dashboards, portfolios and editorial sites.
- `minimalist-ui` — Clean editorial interfaces with a warm monochrome palette, typographic contrast, flat bento grids and no gradients or heavy shadows.
- `redesign-existing-projects` — Audit an existing site or app for generic AI patterns and upgrade it to premium quality without breaking functionality.
- `stitch-design-taste` — Generate agent-friendly DESIGN.md design-system files for Google Stitch that enforce premium, anti-generic UI standards.
