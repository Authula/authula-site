# Productivity Skills

Each subfolder is a self-contained skill. Load the one that matches the work.

- `dont-waffle` — Communicate in clear, concise, plain English with no filler; use whenever writing plans or technical responses.
- `grill-me` — Shortcut that invokes `grilling` to interrogate a plan or design (user-invoked only).
- `grill-with-docs` — Shortcut that invokes `grilling`.
- `grilling` — Relentlessly interview the user in rounds, mapping decisions as a design tree until shared understanding is reached.
- `handoff` — Compact the current conversation into a handoff document saved to the OS temp directory so a fresh agent can continue (user-invoked only).
